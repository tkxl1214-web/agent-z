AI 응답 처리

대화 메시지와 최대 25개의 저장된 기억이 OpenAI API로 전송되어 응답 생성에 사용됩니다. Agent Z는 기본 AI 모델을 다시 학습시키지 않습니다. OpenAI API의 데이터 처리와 보존은 운영자의 API 계정 설정 및 OpenAI의 정책을 따릅니다.

보관과 삭제

대화는 앱의 대화 목록에서 하나씩 삭제할 수 있고, 저장된 기억은 기억 관리 화면에서 삭제할 수 있습니다. 계정 전체 삭제 기능은 현재 제공하지 않으므로 공개 서비스 운영 전 운영자가 계정 삭제 요청을 처리할 연락 방법과 절차를 추가해야 합니다.
