AGENT Z

개인정보 안내

시행일: 2026년 10월 18일

Agent Z는 AI 응답을 기기에서 생성합니다. 사용자의 선택에 따라 대화와 기억을 이 기기에 보관하거나 Firebase 계정에 동기화합니다. 공개 운영 전에 운영자 연락처와 서비스 운영 정보를 추가해 주세요.

수집·저장하는 정보

  • Google 로그인 사용 시 Google에서 전달되는 계정 식별 정보와 프로필 정보
  • Agent Z에 입력한 메시지와 AI 응답. 로그인하지 않은 경우 현재 기기에, 로그인한 경우 Firebase 계정에 저장됩니다.
  • 사용자가 직접 추가한 기억. 로컬 또는 로그인한 계정에 저장되어 응답의 참고 정보로 사용됩니다.

AI 응답 처리

공개 가중치 모델 Qwen3-0.6B-Instruct가 브라우저에서 실행됩니다. 대화문과 저장한 기억은 AI 응답 생성을 위해 외부 AI 서비스로 전송하지 않습니다. 처음 사용할 때 모델 파일을 Hugging Face에서 내려받아 브라우저 캐시에 저장합니다. Agent Z는 사용자의 대화나 기억으로 기본 모델을 재학습시키지 않습니다.

보관과 삭제

대화는 앱의 대화 목록에서 하나씩 삭제할 수 있고, 저장된 기억은 기억 관리 화면에서 삭제할 수 있습니다. 로컬 기록은 현재 브라우저 저장 공간에 남아 있습니다. 계정 전체 삭제 기능은 현재 제공하지 않으므로 공개 서비스 운영 전 운영자가 계정 삭제 요청을 처리할 연락 방법과 절차를 추가해야 합니다.

서비스 제공자

  • Google Firebase: Firebase 로그인을 사용한 인증, 선택한 경우 대화와 기억 저장
  • Google OAuth: 웹 로그인 및 제한된 프로필 정보 확인
  • Hugging Face: 기기 내 AI 실행에 필요한 공개 모델 파일 다운로드
  • GitHub Pages: 웹 앱 파일 제공
